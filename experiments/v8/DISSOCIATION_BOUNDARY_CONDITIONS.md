# V8 Capability-Dissociation Boundary Conditions（PHASE 13 机制检验）

> **目的**：解释为什么 ρ(Overall r, Macro ρ) 在不同宇宙/模型池上从 **−0.27** 变到 **+0.19**。
>
> **结论：既不是多点突变，也不是宇宙差异 —— 是「模型池组成」，具体由 51 个 V6.2
> `split4` 键驱动。** 这要求我在最终报告中把 H1 的数值**改为区间**，而不是单一负值。

## 2. ★ 真正的驱动因素：**模型池组成**（V6.2 `split4` 伪重复）

| 模型池 | n | **ρ(Overall r, Macro ρ)** |
|---|---:|---:|
| `U_CANONICAL` ∩ `n_rows==4473`（仅 V6.2 + V7.1，67 个） | 67 | **−0.2685** |
| 同上，**排除 51 个 V6.2 `split4`** | 16 | **+0.1861** |
| 全 V7.x 族 + align（136 个，本脚本 ALL_rows） | 136 | **+0.1894** |
| `08b` 仅 rowid 子集 | 10 | −0.1969 |
| `08b` 仅 align 子集 | 57 | −0.2130 |
| **HERMES 单点匹配子集** | 136 | **+0.4743** |

**关键对照**：
```
含 51 个 V6.2 split4 键            -> ρ = −0.2685
排除它们（同一宇宙、同样 4473 行）  -> ρ = +0.1861
```
**⇒ 那个「负相关」完全由 V6.2 `split4` 模型的构成决定，不是宇宙或任务的性质。**

**为什么 V6.2 会造成这个效应**：其 51 个键里含 **`L1_random_*`（随机划分）** 模型，
它们 **Overall r 极高（0.66–0.77）但 Macro ρ 极低（−0.06 ~ +0.10）**
（见 `BENCHMARK_SCOREBOARD.csv`）。这些点**同时**拉高 x 轴、拉低 y 轴，
机械地产生负相关。**这是「把在不同划分上训练的模型混在一起比较」造成的人为效应**，
而非「校准与排序在能力上分离」。

## 3. 修正后的 H1 表述（**必须替换原表述**）

**原表述（过度自信，应废弃）**：
> ~~三子集一致为 −0.20 ~ −0.26~~

**修正表述（可辩护）**：

> 在严格 task-specific family-OOD 下，**Overall Pearson 与 Macro per-target Spearman
> 对模型的排序只有弱一致**：跨 6 个模型池/子集的 ρ 落在 **−0.27 到 +0.47**，
> 且**符号取决于模型池组成** —— 含随机划分训练的 V6.2 键时为 **−0.27**，
> 排除后为 **+0.19**，在单点匹配子集上为 **+0.47**。
> **⟨因此「校准轴与排序轴几乎不相关」的说法只能作为观察，不能作为稳健结论。⟩**

**⇒ H1 判定从「PASS（−0.20~−0.26）」下调为：**

```text
H1 Global-vs-within discordance = WEAKLY_SUPPORTED
```
依据：**秩一致在所有池中都偏低**（|ρ| ≤ 0.47，多数 ≤ 0.19），
且存在 **7 ↔ 160** 的极端实质反转（该反转**不依赖**模型池选择，是单模型层面的事实）；
**但**「负相关」不稳健 ⇒ **不能**声称两轴方向相反。

## 4. 仍然稳健的两条子结论（不受上述修正影响）

1. **极端实质反转存在**：`L1_random_A6_global_set_local`
   Overall r 排 **第 7**（+0.666）而 Macro ρ 排 **第 160**（−0.063）。
   这是**单一模型**层面的事实，无需模型池秩相关即可成立。
2. **`Macro ρ` 与 `Eff@10` 的关联强于 `Overall r`**：
   `U_CANONICAL` bootstrap 上 ρ(Macro ρ, Eff@10)=**+0.63 [+0.14,+0.78]** ✅ 排除 0，
   而 ρ(Overall r, Eff@10)=**+0.31 [+0.01,+0.56]**（也排除 0 但更弱）。

## 6. 诚实收尾

**这一轮否定了我自己上一轮的机制假设，并推翻了我两轮前的一个结论。**

- 被否定的假设：「分化由多点突变驱动」→ `MULTIPOINT_NOT_THE_DRIVER`
- 被推翻的结论：「三子集一致为 −0.20 ~ −0.26」→ 实为模型池构成效应；
  **排除 V6.2 后同一宇宙同一行数即变为 +0.19**

**这三次连续修正（+0.18 → −0.26 → 区间）本身就是一条方法学教训**：
**在不控制模型池组成的情况下报告「指标间秩相关」是不可靠的** ——
不同划分训练的模型混在一起会产生人为的相关方向。
这条教训应当写入 V8 的方法学贡献，因为它比原来的点估计更有价值。
