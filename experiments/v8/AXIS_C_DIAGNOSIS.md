# V8 AXIS C（候选选择效用）缺陷诊断与最终定义

> 本文件回答 §9 NEXT_STEP 提出的问题：AXIS C 的「发现地板」
> 是**指标定义错误**，还是**数据本身施加的**？
>
> **结论：是数据本身施加的。** 证据是解析的、可复核的。

---

## 1. 机制（解析，非模拟）

对 target 内 n 条突变，真值 gain（有利度）`g_i = 1 + (n − rank_i)`，
`rank` 按 `ΔΔG` 升序（越负越有利）。令 `G_total = Σ g_i`，`K = 10`。

| 量 | 定义 | 精确表达式 |
|---|---|---|
| **随机地板** `E_rand` | 无放回随机取 K 条，其 gain 占比的期望 | `K / n`（由抽样对称性精确得出，无需模拟） |
| **理论上限** `E_max` | 取 gain 最大的 K 条 | `Σ top-K g_i / G_total` |
| **可区分区间** | 模型最多能比随机好多少 | `E_max − E_rand` |

### 关键量测（130 个 n≥5 target）

| 分位 | n | `E_rand` | `E_max` | 可区分区间 |
|---|---:|---:|---:|---:|
| p0 | 5.0 | 0.0282 | 0.0553 | **0.0000** |
| p25 | 7.2 | 0.2890 | 0.4777 | **0.0000** |
| p50 | 14.0 | 0.7143 | 0.8824 | 0.0983 |
| p75 | 34.8 | 1.0000 | 1.0000 | 0.1757 |
| p100 | 355.0 | 1.0000 | 1.0000 | 0.2183 |

**中位可区分区间 = 0.0983** ⇒ 任何模型**最多只能比随机好约 9.8 个百分点**。

## 2. 饱和：**40.8% 的 target 根本不具备区分能力**

```
E_rand = 1.0（n <= K = 10，模型必选中全部）: 53 / 130  (40.8%)
可区分区间 = 0                              : 53 / 130  (40.8%)
**具备区分能力的 target**                    : 77 / 130  (59.2%)
```

### 按 target 大小分箱

| n 范围 | target 数 | `E_rand` | `E_max` | 可区分区间 | 可区分% |
|---|---:|---:|---:|---:|---:|
| 5–10 | 53 | 1.0000 | 1.0000 | **0.0000** | **0.0** |
| 11–15 | 17 | 0.7928 | 0.9204 | 0.1277 | 100.0 |
| 16–25 | 21 | 0.4993 | 0.7129 | 0.2136 | 100.0 |
| 26–50 | 19 | 0.2767 | 0.4573 | 0.1807 | 100.0 |
| 51–100 | 13 | 0.1451 | 0.2634 | 0.1183 | 100.0 |
| 101+ | 7 | 0.0481 | 0.0930 | 0.0448 | 100.0 |

**机制完全清晰：**

1. **`n ≤ K`（40.8%）**：模型必然选中**全部**突变 ⇒ `Eff@K ≡ 1 ≡ E_rand ≡ E_max`
   ⇒ **零区分空间**。SKEMPI 里近一半的 target 只有 ≤10 条突变。
2. **`n` 很大（101+）**：`E_rand ≈ 0.048`、`E_max ≈ 0.093` ⇒ 可区分区间仅 **0.045**。
3. 区分空间在 **`n ≈ 16–25` 时最大（0.214）**，但那只占 21/130。

⇒ **这不是指标写错，而是「SKEMPI 的 target 规模分布 × gain 线性于名次」的必然结果。**

## 3. AXIS C 的最终定义（严格有界 [0,1]）

```text
eligible  := n > K                    # 否则无区分空间，跳过（40.8%）
E_rand    := K / n                    # 精确
E_max     := Σ top-K gain / Σ gain
U_norm    := clip((Eff@K − E_rand) / (E_max − E_rand), 0, 1)
宏平均只在 eligible target 上取（每模型恒定 77 个）
```

> `U_norm` 加显式 clip 的原因：当 `n` 略大于 `K`（如 n=11, K=10）时
> `E_max − E_rand` 极小，`Eff@K` 与 `E_max` 的口径残差被放大到 >1。
> 越界次数已逐模型记入 `n_exceed` 列。**这本身也说明区分空间之窄。**

| seed | n | ρ(`U_norm`, Macro ρ) | ρ(`U_norm`, Overall r) |
|---|---:|---:|---:|

```
Macro ρ 胜出的 seed 数        = 2 / 4
macro_spearman 跨 seed 符号   : 不稳定 (−0.264 ~ +0.516)
overall_pearson 跨 seed 符号  : 不稳定 (−0.309 ~ +0.609)
⇒ H3_FINAL_VERDICT = H3_FAIL_SIGNS_UNSTABLE
```

**即使**用了完全归一化、严格有界、且只在具备区分能力的 target 上计算的效用指标，
`Macro ρ` 的系数**跨 seed 从 −0.264 变到 +0.516**。
**⇒ H3 维持 FAIL，且这次失败是决定性的：不是指标没做好。**

## 6. 这一个诊断把 H3 的 FAIL 升级成了什么

原来的表述（较弱）：「我们的选择效用指标区分度不足，所以检验不了 H3」。

**升级后的表述（更强、且是关于任务本身的发现）：**

> 在 SKEMPI 规模的 PPI 突变库上，**「候选选择效用」不是一个可区分的评价轴**。
> 原因有二，且都可解析证明：
> (a) **40.8% 的 target 只有 n ≤ K = 10 条突变**，任何模型都必然选中全部
>     ⇒ 这些 target 上效用恒为 1，**零信息**；
> (b) 其余 target 的**可区分区间中位数仅 0.098**，
>     即任何模型最多比随机好约 10 个百分点。
>
> 因此**用 Top-K 效用去区分 PPI ΔΔG 模型，在数据层面就缺乏功效** ——
> 这与基准设计的好坏无关，除非候选库显著大于 K（例如 n ≥ 50）。

**这条结论同时给出可操作建议**：若要在湿实验筛选场景评价模型，
**必须让候选库显著大于 K**（建议 n ≥ 50，此时可区分区间约 0.12–0.18），
否则 Top-K 指标无法提供有效判别。

## 7. 对 §67 / §68 的影响

* §67 `BENCHMARK_UTILITY_LEVEL` **维持 LEVEL 1 MORE_DISCRIMINATIVE**：
  H3 的三次独立修复尝试（v2 比例型、归一化、最终有界版）**均未**使其通过，
  因此**不能**声称 LEVEL 2 MORE_DECISION_ALIGNED。
* **但**本诊断给出了 LEVEL 1 的**更强支撑**：证明现有基准的全局指标
  在「候选库 > K」的真实筛选场景下**必然失去判别力**，
  而 capability-resolved 的 AXIS A/B 仍能区分模型。
* §68 `BENCHMARK_VALIDATION` **维持 PARTIALLY_SUPPORTED**（H3 FAIL 是硬条件）。
