## 结论

### 标记：**`OLD_SHUFFLE_BUG_CONFIRMED`**

**数学事实（本审计用断言验证）**：对每个 target 做组内置换会
**保持该 target 的预测均值不变**，因此在同一 row universe 上必有

```
C_B(shuffle) ≡ C_B(original)
C_W(shuffle) ≈ 0
r_full(shuffle) = C_B(shuffle) + C_W(shuffle) ≈ C_B
```

**因此 V6.2 §3.7 的表述必须修正**：

> ❌ 原文：「把靶点内的突变顺序完全打乱后，全局 Pearson 掉到 ≈ 0」
> —— 该表述**与协方差分解自相矛盾**，且**不得**引申为
> 「全局 Pearson 全部来自 between-target」（V6.2.1 §关键科学纪律 1）。

> ✅ 正确表述：within-target shuffle **只**消除了 `C_W`
> （组内排序贡献），而 `C_B`（跨靶点贡献）**在数学上必然保留**。
> 因此 `r_shuffle` 是一个**下界估计**：它等于「仅靠跨靶点信息所能达到的
> 全局 Pearson」。二者之差才是**组内排序的真实贡献**。
